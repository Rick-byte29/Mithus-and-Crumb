# Mithas & Crumb

A responsive bakery and Indian sweet shop demo based in Bongaigaon, Assam.

## Run locally

This is a static HTML, CSS and JavaScript website. No build or package installation is required.

```sh
python3 -m http.server 8080
```

Open http://localhost:8080 in your browser. Any static host can serve the repository root.

## Features

- 12 page sections with a filterable sample menu, celebration planner, pairings, gifting, testimonials and location map
- Click-to-call buttons: +91 9101035255
- Mobile navigation, scroll reveals, image motion and three-second loading intro
- Playfair Display and Roboto via Google Fonts
- Reduced-motion support

## Files

- `index.html`: page content
- `style.css`: responsive styles and animations
- `script.js`: navigation, filters, dialogs, sample enquiry and scroll progress
- `*.jpg`: website images

The business branding, menu, prices, testimonials and opening hours are illustrative. The celebration planner does not submit orders or bookings. The map shows the Bongaigaon area, not a verified shop address. Call buttons use the supplied contact number.
